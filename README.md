# منصة التحليل المالي والتقارير المحاسبية (Arabic-first)

تطبيق متكامل لمكتب محاسبة مهني في المملكة العربية السعودية: استيراد ميزان المراجعة والقيود والسجلات الفرعية، فحوصات محاسبية حتمية، قوائم مالية ونسب ومقارنات، ملاحظات قابلة للتتبع، تسويات مقترحة بسير اعتماد، مساعد ذكي اختياري، ومركز تقارير يصدر PDF عربي على ترويسة المكتب.

## المكوّنات
| المجلد | الوصف |
|---|---|
| `server/` | Node.js + Express + TypeScript + PostgreSQL. المحرك المحاسبي في `server/src/engine` (حساب عشري دقيق، بلا أرقام عائمة). |
| `client/` | React + TypeScript + Vite. واجهة عربية RTL كاملة. |
| `python/` | أدوات استخراج PDF (`pdfplumber`) و`.xls` (`xlrd`) تُستدعى من الخادم. |
| `docs/` | المعمارية، النشر، دليل المستخدم. |
| `scripts/` | تثبيت الخطوط العربية على النظام. |

## التشغيل السريع (تطوير)
```bash
# المتطلبات: Node 20+، PostgreSQL 14+، Python 3.10+ (اختياري للـ PDF/XLS)
cp .env.example .env            # عدّل DATABASE_URL و JWT_SECRET و ADMIN_PASSWORD
createdb abusamir               # أو عبر psql
npm install
npx playwright install chromium # متصفح توليد PDF (مرة واحدة)
pip install -r python/requirements.txt
./scripts/install-fonts.sh      # خطوط ترقيم الصفحات في PDF
npm run dev                     # الخادم على 4000 والواجهة على 5173
```
أول دخول: `ADMIN_EMAIL` / `ADMIN_PASSWORD` من `.env`، ويُطلب تغيير كلمة المرور فورًا.

## مبادئ تصميم مهمة
- كل حساب مالي يتم في كود حتمي؛ الذكاء الاصطناعي يفسّر فقط ومخرجاته تُتحقق من مخطط وتُفحص أرقامها مقابل المدخلات.
- لا يُرحَّل أي قيد تلقائيًا ولا تُعدَّل السجلات الأصلية. الملفات الأصلية تُحفظ ببصمة SHA-256.
- التقارير تحليل إداري/دعم محاسبي وليست رأي مراجع مستقل، وتمر بمسودة → مراجعة → اعتماد.
- عزل بيانات العملاء، أدوار وصلاحيات، سجل تدقيق لكل إجراء، تشفير اختياري للملفات المخزنة.
