# دليل المحاسب المختصر

1. **ترويسة المكتب**: اسم المكتب، الشعار، بيانات الاتصال، الهوامش، التوقيع/الختم (لا تُدخل أرقام تراخيص غير صادرة فعلًا).
2. **العملاء → الارتباطات**: أنشئ العميل ثم ارتباطًا بنوعه (تحليل إداري / مراجعة متفق عليها / مسك دفاتر / ضريبي / تأكيد) وفتراته (حالية وسابقة).
3. **رفع المستندات → الاستيراد**: ارفع ميزان المراجعة (Excel/CSV). المعالج يقترح صف العناوين وربط الأعمدة؛ راجع الربط، شغّل التحقق، ثم اعتمد بتأكيد صريح. صفوف الإجماليات والعناوين تُستبعد تلقائيًا ولا يُخترع أي رقم.
4. **ميزان المراجعة**: راجع التصنيف الآلي (انقر على الحساب لتصحيحه)، حدد حد الأهمية النسبية إن أردت، وشغّل الفحوصات. كل ملاحظة لها مرجع وصف مصدر واحتساب.
5. **التحليل المالي**: ولّد القوائم والنسب والمقارنة. "بيانات غير كافية" تعني تعذر الاحتساب لا رقمًا مفترضًا. فحوصات اليومية والسجلات الفرعية من التبويب الأخير.
6. **المحاسب الذكي** (اختياري): يحتاج تفعيلًا وتأكيدًا؛ ملاحظاته تُعلَّم "ذكي" وتتطلب مراجعة بشرية.
7. **الملاحظات والتسويات**: اقبل/ارفض/عالج كل ملاحظة مع ملاحظة مراجع؛ أنشئ تسويات مقترحة متوازنة تمر بالمراجعة والاعتماد ولا تُرحَّل آليًا.
8. **التقارير**: اختر قالبًا (14 نوعًا + مخصص)، حرّر الأقسام (إخفاء/ترتيب/نصوص/إضافة)، عاين، أرسل للمراجعة، اعتمد (مستخدم مختلف عن المُعد)، ثم صدّر PDF على الترويسة أو Excel للجداول الداعمة. المسودة تحمل علامة "مسودة".
9. **سجل التدقيق**: من فعل ماذا ومتى.
