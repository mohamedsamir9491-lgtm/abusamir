# دليل المستخدم: إصدار تقرير لأي شركة من البرنامج خطوة بخطوة

هذا الدليل يصف الخطوات من الواجهة فقط (بلا أوامر). كل خطوة تذكر الصفحة والزر كما يظهران في البرنامج.

## 0. إعداد المكتب مرة واحدة
1. صفحة **ترويسة المكتب**: اسم المكتب بالعربية والإنجليزية، الترخيص، السجل، العنوان، الهاتف، البريد، الرقم الضريبي.
2. ارفع الشعار والتوقيع والختم، وفعّل "استخدام التوقيع/الختم" إن أردت ظهورهما على التقارير وخطابات الارتباط.
3. صفحة **المستخدمون والصلاحيات**: أنشئ مستخدمًا بدور **مراجع** غير حسابك. المُعد لا يستطيع تعليم تقريره "تمت المراجعة"؛ المراجعة والاعتماد يتمان من هذا المستخدم.

## 1. العميل
صفحة **العملاء** → **+ عميل جديد**: الاسم القانوني، نوع الكيان، السجل التجاري، الرقم الضريبي، جهة الاتصال. كل شركة في المجموعة عميل مستقل (لا تُخلط بيانات شركتين في عميل واحد).

## 2. الارتباط وخطاب الارتباط
1. صفحة **الارتباطات** → **+ ارتباط جديد**: العميل، نوع الارتباط (تحليل مالي إداري / مراجعة وفق إجراءات متفق عليها / ...)، الإطار، العملة، والفترات (تاريخ البداية والنهاية ودور الفترة: حالية / سابقة).
2. افتح الارتباط → زر **خطاب الارتباط**: تُعبأ الحقول افتراضيًا من بيانات العميل والارتباط والمكتب (المرسل إليه، الموضوع، نطاق الخدمات، المخرجات، مسؤوليات الطرفين، حدود الارتباط، الأتعاب، المدة، السرية، الإنهاء، الموقّعون). عدّلها ثم **حفظ كمسودة** أو **حفظ وتعليم كصادر**. يُمنح الخطاب رقمًا تلقائيًا (ENG-السنة-التسلسل). المعاينة تظهر على ترويسة المكتب، وزر **PDF للطباعة** يولّد الملف ويحمّله.

## 3. رفع ميزان المراجعة واستيراده
1. صفحة **رفع المستندات**: اختر الارتباط والفترة ونوع المستند "ميزان مراجعة" وارفع الملف (Excel أو CSV أو PDF). بعد الرفع ينتقل البرنامج تلقائيًا إلى معالج الاستيراد.
2. معالج **الاستيراد والتحقق** (خمس خطوات: رفع → تحديد الورقة والعناوين → ربط الأعمدة → التحقق → الاعتماد):
   - تأكد أن الربط المقترح صحيح (رمز الحساب، الاسم، الرصيد الافتتاحي، مدين الفترة، دائن الفترة، الرصيد الختامي) ثم **حفظ الربط**.
   - راجع تقرير التحقق (سليم / تحذير / خطأ / مستبعد) وفروق التوازن (الافتتاحي والحركة والختامي يجب أن تكون صفرًا).
   - **تأكيد الاعتماد** ثم **الانتقال لميزان المراجعة**. إعادة استيراد الملف نفسه تستبدل الأسطر القديمة.

## 4. ميزان المراجعة والتصنيف والفحوصات
1. صفحة **ميزان المراجعة**: اختر الارتباط والفترة.
2. زر **إعادة التصنيف الآلي**: يصنف كل حسابات الدليل بحسب الاسم والرمز وجانب الرصيد (مثل جاري الشريك المدين = مستحق من المساهمين). استخدمه بعد كل استيراد جديد.
3. راجع عمود "بند القوائم" لكل حساب؛ لتعديل حساب يدويًا اضغط على السطر وغيّر بند القوائم ثم **حفظ**.
4. زر **تشغيل الفحوصات المحاسبية** (اختياريًا بحد أهمية نسبية): يُنتج ملاحظات TB-001 إلى TB-025 ويحفظها في صفحة الملاحظات.

## 5. القوائم المالية والنسب
صفحة **التحليل المالي** → زر **توليد القوائم والنسب**. تظهر قائمة المركز المالي والدخل والتغيرات وحقوق الملكية والتدفقات (المشتقة من الميزان، استرشادية) والنسب، مع "غير ذات معنى" حيث لا يصح الاحتساب. يجب تشغيل فحوصات الميزان أولًا.

## 6. (للمجموعات) التوحيد الدفتري
صفحة **التوحيد الدفتري**:
1. اختر ارتباط الشركة الأم وفترتها.
2. **+ إضافة تابعة** لكل شركة تابعة: ارتباطها وفترتها، نسبة الملكية، رموز حساب الاستثمار لدى الأم (مثال أسس: 106021 لجراند و106023 ليونيسكوب)، رموز "جاري الأم" لدى التابعة (مثال: 202005)، تاريخ اكتساب السيطرة وأساسه (تأسيس من الأم / شراء)، وطبيعة رصيد جاري الأم (مؤقت حتى الإثبات / اكتتاب موثق / أخرى).
3. **+ إضافة شركة** لكل شركة بلا قوائم (مثل ديزرت جيت وبيلد جلوب): رموز الاستثمار والذمم المدينة والدائنة لدى الأم، وحالة السيطرة.
4. **تشغيل التوحيد**: تظهر الحالة (مدعومة / غير مكتملة مع الأسباب)، ورقة العمل، قيود الاستبعاد وأدلتها، سجل الفروق غير المحسومة، ومطابقة الاستثمار برأس المال. الإعدادات تُحفظ في المتصفح لإعادة التشغيل لاحقًا.

## 7. الملاحظات والتسويات
صفحة **الملاحظات والتسويات**: راجع كل ملاحظة (فتح / قيد المراجعة / معالجة / مرفوضة)، وأضف تسويات مقترحة بقيود متوازنة. الملاحظات المعالجة والمرفوضة لا تظهر في التقارير.

## 8. التقرير
1. صفحة **التقارير** → **+ تقرير جديد**: اختر القالب (تحليل إداري، مراجعة ميزان، تحليل القوائم، النسب، الأخطاء والتسويات، المستندات الناقصة، مخصص...) والعنوان.
2. في محرر التقرير: فعّل/عطّل الأقسام، رتّبها، عدّل النصوص والجداول، أو **إضافة قسم** (مثل "نص حر" للشرح، أو "التوحيد الدفتري للمجموعة" لإدراج نتيجة التوحيد الأخيرة، أو "مصادر البيانات" الذي يعرض الآن سجل مصادر كل شركة في المجموعة بالبصمة والنسخة).
3. **حفظ** (ينشئ نسخة جديدة مع ملاحظة التغيير) → **معاينة** → **تصدير PDF** و**تصدير Excel** من تبويب النسخ.
4. التقرير يبقى **مسودة** بعلامة مائية حتى يراجعه مستخدم آخر.

## 9. المراجعة والاعتماد والإصدار
1. يسجل المراجع الدخول بحسابه ويفتح التقرير → **تمت المراجعة** (بعد قراءة فعلية).
2. **اعتماد للإصدار** (يرفضه النظام إن كانت القوائم غير متوازنة أو توجد أخطاء حسابية حرجة مفتوحة).
3. **تعليم كصادر** ثم تصدير النسخة النهائية بلا علامة مائية.

## 10. تنظيف التقارير غير السليمة
في قائمة **التقارير** زر **حذف** بجانب كل تقرير (لمن يملك صلاحية حذف التقارير، وهي ممنوحة لمدير النظام). الحذف نهائي لصف التقرير ونسخه ويُسجَّل في سجل التدقيق بالمرجع والعنوان والحالة؛ ملفات PDF السابقة تبقى في مخزن الملفات.
